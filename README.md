# BÜK.

**READ. THINK. REBEL.**
*A digital library of ideas. An archive of radical reading.*

BÜK. es un archivo personal para registrar los libros físicos que compras: cada libro recibe un número de inventario y una sección numerada, y puedes buscarlo por título, autor, categoría o ISBN.



Con el teléfono, toca **ISBN** y apunta al código de barras de la contraportada: BÜK. lee el ISBN, suena un pitido y abre la ficha llena con los datos de Google Books y Open Library. Con «Seguir registrando», la cámara vuelve a abrirse después de cada libro.

La primera vez que abres el archivo te pide tu nombre, tus apellidos y, si quieres, una foto. Puedes cambiarlos después desde tu avatar, arriba a la derecha.
